# OwnTech branding used by OwnStudio

Copied from OwnTech Technologies' brand guidelines (`Charte graphique`, `charte_owntech.pdf` and `assets/`). Change them there first, then copy them here.

## Not covered by OwnStudio's LGPL-2.1 licence

- **Logos** (`logos/`): the OwnTech logomark and logotype are OwnTech Technologies' marks. The LGPL-2.1 licence of OwnStudio's code does not cover them.
- **Fonts** (`fonts/`): they are open-source fonts, but their licence texts weren't in the brand folder. Add each font's licence file (presumably the SIL Open Font License) next to it before any public release:
  - Atkinson Hyperlegible (Braille Institute)
  - VG5000 (Velvetyne)
  - Ronzino (Collletttivo)

## Brand rules applied

| Element | Guideline | In OwnStudio |
| --- | --- | --- |
| Brunswick green `#234D45` | Main colour | Title bar, workbench bar, primary buttons |
| Light yellow `#F9F77F` | Main colour | Active workbench, focus |
| Black `#000000` | Text | Text in the light theme |
| Azure `#6C8AFF`, light azure `#B6C9F8` | Secondary | Links, selection |
| Persimmon `#FF6112` | Secondary | Warnings and safety (the Specification layer's red overlay) |
| VG5000 | Titles | Workbench names, Home titles |
| Ronzino | Emphasis | Mission titles |
| Atkinson Hyperlegible | Body text | All interface text (code stays monospace) |
