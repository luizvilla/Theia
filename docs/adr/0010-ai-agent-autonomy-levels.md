# The AI agent works at three autonomy levels; hardware safety never depends on it

The AI agent may freely edit files, run Design calculations and run the simulator target. It must ask for confirmation each time before flashing the board or starting a bench run. It may never change the safety envelope or bypass a trip. A human may grant the agent the right to run automated bench tests unattended, but only after the instrument current and voltage limits have been set and confirmed within the safety envelope, so that the physical limits, not the agent, guarantee safety.
