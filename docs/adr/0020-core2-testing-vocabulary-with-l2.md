# Testing reuses Core2's vocabulary and tooling, with L2 for the bench

Test procedures, test cases, test campaigns, test records, the findings register and the campaign runner, record writer and review page come from Core2 rather than being invented again. Core2 has L0 (one object, synthetic inputs) and L1 (closed loop against the plant model); OwnStudio adds L2 (closed loop on the bench). The target switch of ADR 0003 is the choice between L1 and L2 for the same test case. Every requirement is verified by at least one test case with a numeric pass criterion, and the link is checked, so a requirement without a test case shows as a gap on the Verification layer. In the skeleton, L2 waveforms come from the firmware scope (Core4's triggered capture), not from external instruments.
