# This application absorbs modular's Lab features and retires modular

The goal is one application that aggregates the whole OwnTech workflow. modular (Electron + Freeboard dashboards, serial and ThingSet data sources, CSV recording, mcumgr flashing) is not kept alongside it: its ideas are integrated into the Lab workbench as panels, and modular is retired once that is done. Two OwnTech desktop apps competing for the same students would recreate the separate-tools problem seen in Typhoon HIL Control Center. The earlier Theia experiment inside the modular repository (`owntech_extension_overhaul` branch) is abandoned and is not the starting codebase; its implementation journal remains useful as a list of known Theia build problems. Jean Alinei follows modular's development and is kept informed.
