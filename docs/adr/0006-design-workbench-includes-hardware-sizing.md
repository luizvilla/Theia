# The Design workbench includes hardware sizing in v1

v1 Design does not stop at control design on a fixed board: users also size the hardware. Either the tool exposes how the fixed board (Twist) was sized, or the work starts from a board with a free design choice (the Ownverter has no output filter, so its filter is designed by the user). The narrower option (configuration and control design on a pre-modelled Twist) was proposed and rejected because the user study must collect feedback on the breadth and depth of the Design workbench, which a control-only Design cannot provide.
