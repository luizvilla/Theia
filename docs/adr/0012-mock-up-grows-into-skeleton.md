# The mock-up is the real Theia application with canned data, and grows into the walking skeleton

The first version shown to colleagues is the real Theia application, with every data source (sizing, Pulsim runs, flashing, board and instrument data) behind an interface that first serves canned results. Each canned source is replaced by the real one, so the mock-up turns into the walking skeleton without being thrown away. A throwaway clickable mock-up was rejected: the goal is a working skeleton tested with students about one month after this decision (target: early December 2026).
