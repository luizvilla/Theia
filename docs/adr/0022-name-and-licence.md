# The application is called OwnStudio (working name) and licensed LGPL-2.1

The working name follows the OwnTech family (OwnPlot, OwnModels, ownscope). The licence matches OwnTech's software, for example the LGPL-2.1 comm protocol files. Eclipse Theia is EPL-2.0, which allows an LGPL-licensed application on top. Final branding is decided later.
