# Panels are rebuilt natively in OwnStudio, reading a subset of modular's dashboard format

modular's dashboards are not imported as they are. modular is a Freeboard (jQuery-era) dashboard inside Electron, and its hardware access lives in the Electron main process: `app/main.js` has about 4,200 lines and 89 IPC handlers for serial, USB, flashing, ThingSet and file saving, bridged by a 716-line preload script. Running Freeboard in a Theia webview is easy, but every one of those IPC handlers would have to become a Theia backend service behind a webview message bridge. That is where the abandoned Theia spike in the modular repo struggled (see its journal: postMessage bridge, backend URLs in the Electron renderer). Instead, OwnStudio implements its own small set of panel widgets (plot with uPlot, gauge, numeric display, button, setpoint) on top of the single ThingSet connection it needs anyway for procedures, and reads the subset of modular's dashboard JSON that maps onto those widgets.
