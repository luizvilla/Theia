# BUCK-REF-01, generated by the editor.
# Hand edits become a "custom step" block.
def step_response(t, step, channels):
    t.arm(channels, window_s=0.100,
          pretrigger_s=0.020)
    t.update(wVoltageRef_V=step.to)
    waveform = t.capture()
    return waveform, settling_time(
        waveform["V_LOW1"], step.to, band=0.02)

def run(t, ctx):
    t.check_setup()
    load = ctx.ask("Load on LOW1 (ohm)")
    t.update(wVoltageRef_V=10.0)
    t.power_on()          # OwnStudio asks
    for step in STEPS:
        w, ts = step_response(t, step,
                              ["V_LOW1", "I_LOW1"])
        if ts <= 0.010:
            ctx.record("REQ-TRACKING", PASS)
        else:
            ctx.record("REQ-TRACKING", FAIL, ts)
    t.monitor(["V_HIGH", "I_LOW1"],
              period_s=0.1, duration_s=2)
    t.power_off()
    ctx.twin()

What makes it readable

Nesting. C-shaped blocks (repeat, if/else, "while the converter is on") hold other blocks; the indentation is the structure.
Your own blocks. A group of blocks becomes a named block with inputs ("Step response"), used as one line, defined once.
Collapse. Any container folds to one line with a count.
Sentences, not code. Blocks read as instructions with slots; variables are dragged from the list built from the setup.
Structured only. No arbitrary jumps, so the Python is clean and the editor can read back its own output.
Theme. Blockly's flat renderer with OwnStudio's colours, no puzzle-piece cartoon: only a small notch shows where blocks join.
